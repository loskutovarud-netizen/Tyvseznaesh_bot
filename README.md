# 🧠 Telegram-бот «Где мой тормоз?»

## Быстрый запуск

### 1. Создай бота
- Открой @BotFather в Telegram
- Отправь /newbot → придумай имя → получи токен
- Вставь токен в `config.py` → `BOT_TOKEN`

### 2. Узнай свой Telegram ID
- Открой @userinfobot → получи ID
- Вставь в `config.py` → `ADMIN_ID`

### 3. Установи зависимости
```bash
pip install -r requirements.txt
